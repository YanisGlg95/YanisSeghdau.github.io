# Portfolio — Yanis Seghdau

Projet React (Vite), prêt à intégrer dans un dépôt git.

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

## Build de production

```bash
npm run build
```
Le résultat est généré dans `dist/`, prêt à déployer (GitHub Pages, Vercel, Netlify...).

## À faire avant publication

Dans `src/data.js`, remplacer les entrées `"à compléter"` de `CONTACT_LINKS` par tes vrais liens LinkedIn, GitHub et GitLab.
